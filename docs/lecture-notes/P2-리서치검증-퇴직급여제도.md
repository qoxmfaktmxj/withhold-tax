## 1. 머리말 — 목적·방법·면책

### 목적
강의 녹취(STT)에서 추출한 퇴직급여제도 실무 명제들을 **국가법령정보센터(law.go.kr)·국세청(nts.go.kr)·찾기쉬운 생활법령정보(easylaw.go.kr)·고용노동부 행정해석·대법원 판례** 등 1차출처와 대조하여, 사이트 콘텐츠로 게재 가능한 수준으로 확정(verify)·교정(correct)하거나 추가확인(flag)한다.

### 방법
- 강의 단위(unit)별로 명제(claim)를 추출 → 1차출처 웹검색·페치로 검증(verifiedStatement) → **적대적 검증자(adversarial verifier)**가 인용 정합성(citationSupports)과 권고 상태(recommendedStatus)를 재판정.
- 본 문서의 **상태(verifyStatus)는 적대적 검증자의 `recommendedStatus`를 우선 반영**한다(리서처의 1차 판정과 다를 경우 검증자 판정 채택).
- 상태 정의: **확정** = 1차출처로 입증, 게재 가능 / **확인필요** = 1차출처 미확보 또는 견해 대립·인용 정합성 약함, 단정 금지 / **불일치(교정)** = 강의(STT)와 1차출처가 다름, 정정값 반영 필요.

### ⚠️ 면책 (CLAUDE.md 세무·노무 면책 원칙)
모든 수치·기한·세율·조문번호는 **국가법령정보센터/국세청/홈택스/고용노동부 최신 예규로 최종 확인해야 하는 실무 참조용**이다. 단정적 법률·세무 자문으로 사용하지 말 것. 각 사실에는 `asOf`(검증 기준일)와 출처를 부착한다.

### 검증 기준일
- **asOf: 2026-06-28** (현행 시행 법령 기준)
- 강의 녹취 시점: 2026-06-23~24
- 일부 항목은 2025.11.11 / 2026.3.20 / 2026.4.23 / 2026.7.1 시행 개정과 강의 시점이 어긋날 수 있어 개정연혁 표기 병행.

## 3. ★ 강의 교정 목록 (강의 STT ≠ 1차출처) — 최중요

> 강의 녹취와 1차출처가 다른 항목. **배율·조문번호·시행일** 중심으로 정정값과 근거를 명시한다. 사이트 게재 시 강의 표현이 아니라 아래 **정정값**을 채택할 것.

### 🔴 교정 1 — DB 최소적립비율 100% 시행일 (가장 중대한 사실오류)

| 구분 | 내용 |
|---|---|
| **강의 claim** | 최소적립금 의무적립비율 100% 전면 시행 = **2021.1.1** |
| **🔴 정정값** | **2022.1.1** 전면 시행. 단계표: 80%(2016~2018) → **90%(2019~2021)** → **100%(2022.1.1~)**. 100% 적용은 당초 2021 예정이었으나 **코로나19로 2022.1.1로 1년 연기**됨. |
| **근거** | 근로자퇴직급여 보장법 시행규칙(시행령 제5조 위임), 복수 독립출처 일관 확인 |
