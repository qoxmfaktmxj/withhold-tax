## 1. 근속기간(계속근로기간) 심화

📘 교재 p.71~75

### 1-1. 휴직기간은 근속 포함이 원칙
- 휴직기간도 근속기간에 포함 → 그 기간 포함해 퇴직금 지급.
- 🛠️ **시스템 개발 포인트** — 휴직기간이 근속에 포함되면 **DC 가입자는 그 기간도 부담금 납입** 필요(퇴직금 지급의무 = DC 부담금 납입의무, 같은 논리).

### 1-2. 근속연수 환산 방식 — 2가지 모두 유효
📘 교재 p.71

| 방식 | 계산 |
|---|---|
| ① 총재직일수 ÷ 365 | 노동부 퇴직금계산기 방식 |
| ② 연·월·일 각각 환산 | 예: 7년 + 1개월/12 + 15일/360 |

- 법원·노동부 모두 "일수를 **연으로 환산**"만 요구, 방식은 자율 → **둘 다 맞음**.
- 실무상 두 방식 결과가 미세하게 다른 이유 = **윤달 미고려**(실무상 윤달 일일이 반영 불가).
- 예외 주의: 1년 근무 + 윤년이면 총재직 366일 → 365로 나누면 1년 초과로 계산되나, 이 경우는 **1년**으로 봐야 함.

> 🛠️ **시스템 개발 포인트** — 근속연수 환산 알고리즘은 ①(일수÷365) 또는 ②(연/월/일 분리) 중 택1 가능하나, **회사 표준 1개 고정**할 것. 1년 경계·윤년 보정 엣지케이스 테스트 필요.

### 1-3. 근속에서 제외 가능한 기간 (예외)
📘 교재 p.75

| 기간 | 근속 포함? | 회사규정(단협·취업규칙)으로 제외 가능? |
|---|---|---|
| 병역의무기간 | 원칙 포함 | **제외 가능** |
| 개인사정·개인질병·학업(유학) 휴직 | 원칙 포함 | **제외 가능** |
| **법정 육아휴직(1년 이내)** | 포함 | ❌ 무조건 포함 |
| **약정 육아휴직(법정 1년 초과분)** | 포함 | **제외 가능**(개인사정 휴직으로 봄) |
| **징계 정직기간** | 포함 | ❌ 제외 불가 (회사규정에 제외 명시해도 행정해석상 불가) |

- 핵심 오해 주의: "근로자 귀책"이라는 점에서 징계가 더 귀책 같지만, **행정해석은 개인질병·약정휴직 등에만 제외 약정의 효력을 인정**하고 징계 정직은 제외 불가.

> 🛠️ **시스템 개발 포인트** — 근속에서 제외된 기간은 **DC 부담금 납입 불요**(퇴직금 지급의무 없음 = 동일 논리). 예: 2024년 약정 육아휴직 + 회사규정 제외 → 2024년 DC 부담금 미납입. 퇴직소득 원천징수영수증에는 입사일/기산일/퇴사일 + **제외기간(개월수)** 을 별도 항목(교재상 ‘24번’ 칸)에 기재해 기산 보정.

## 2. 평균임금 산정에서 제외되는 기간·임금

📘 교재 p.63~67

직전 3개월(평균임금 산정기간)에 휴직 등이 끼었을 때 처리.

### 2-1. 제외 vs 포함
| 구분 | 항목 | 처리 |
|---|---|---|
| **제외**되는 기간·임금 | 수습기간, 육아휴직, 출산휴가, 업무외 부상·질병 휴직, 개인사정 휴직 | 그 기간과 임금을 **빼고** 나머지로 평균임금 산정 |
| **포함**되는 기간·임금 | 무단결근, 대기발령, 감봉, 징계기간 | **포함**(무임금이어도 0으로 포함 → 평균임금 낮아짐, 근로자 귀책 감수) |

### 2-2. 제외기간이 3개월 미만 vs 이상
| 케이스 | 평균임금 산정 |
|---|---|
| **3개월 미만** — 휴직 종료·복직 후 1~2개월 근무하다 퇴직 | 휴직기간 빼고 **복직 후 실제 근무기간 임금**으로 산정 (예: 1개월치 ÷ 30일) |
| **3개월 이상** — 휴직 중 퇴직 | **휴가 첫날로 거슬러** 그날부터 역산 3개월 임금으로 산정 |

### 2-3. 가져온 개월수에 비례하는 배율
- 매월 지급 임금을 **3개월치** 가져오면 → 상여금 ×3/12. **1개월치**만 가져오면 → 상여금 ×1/12.

> ⚠️ **1차출처 확인 필요** — 강사는 "10분의 3", "10분의 1"로 표현하나 표준은 **가져온 개월수 ÷ 12**(예: 3/12, 1/12). 1차 §9-1과 동일한 STT 의심. 통합 단계에서 확정.
> 🛠️ **시스템 개발 포인트** — 평균임금 산정 시 상여·연차 배율은 고정값(×3/12)이 아니라 **유효 산정 개월수에 연동**해야 함. 휴직 보정으로 산정기간이 1개월이면 상여도 ×1/12.

## 3. 평균임금의 2대 기본개념 + 평균임금 최저보장

📘 교재 p.65

### 3-1. 두 개념
1. **사후적 개념** — 실제 지급된 임금으로 계산. (근로계약서·급여대장 기준)
2. **통상의 생활자금 원리 반영 + 중복배제** — 정상 근무 시 받을 임금으로 생활했을 것 → 명절상여 1회·연차수당 직전 1회만(중복 배제).

- 두 개념은 휴직·복직 케이스에서 **충돌** → 행정해석이 시기에 따라 바뀜. **최근 행정해석은 통상의 생활자금 원리**(정상근무 가정 임금 포함) 쪽으로 기움(법원 판결 기조 반영).

### 3-2. 평균임금 최저보장 제도
- 산정한 **평균임금 < 통상임금**이면 → **통상임금을 평균임금으로** 사용(최저 보장).
- 비교 방법: 통상임금은 시간급 → 1일(8시간) 환산해 **1일 평균임금과 비교**, 큰 값 적용.
- **고정수당 위주**(연장·연차수당 거의 없는) 회사는 통상임금 > 평균임금인 경우가 많음 → 통상임금으로 퇴직금.
- 실무 사례: 평균임금을 "정확히" 계산해 지급했는데 임금체불 진정이 들어옴 → 통상임금(최저보장)과 비교를 안 해서. 고정수당 위주면 통상임금 비교 필수.

> 🛠️ **시스템 개발 포인트** — 퇴직금 = **max(1일 평균임금, 1일 통상임금) × 30 × 근속연수**. 통상임금(시간급)→1일(×8h) 환산 비교 로직 필수. 통상임금의 산정시점은 **퇴직(산정사유 발생) 시점**(평균임금 산정 시점 아님) → 임금인상 반영분으로 비교.

### 3-3. 사후적 개념 적용 — 연차수당
- 연차수당은 **직전 수령분**만 평균임금 산입(퇴직연도 1월 부여 연차 아님).
- 절세 팁: 퇴직금 많이 받으려면 **직전 연차휴가를 쓰지 말 것**(미사용수당이 직전 수령분에 잡힘). 단, 퇴직연도 부여 연차를 안 쓰는 건 효과 없음.

### 3-4. 실무 조언
- 평균임금 판단이 애매하면 → **근로자에게 불리하지 않게(유리하게)** 처리하는 것이 가장 깔끔(분쟁 회피). 행정해석이 자주 바뀌므로 기본 개념으로 접근.

## 4. 퇴직금 압류 (실무 관점)

📘 교재 p.79

- **압류 개시 시점 = 법원 압류(가압류·추심)명령이 회사에 도달한 때**. 채권자가 찾아와 요구해도 명령 도달 전엔 압류 불가.
- 급여지급일이 압류명령 도달일보다 **빠르면** 그 달 급여는 압류 대상 아님(예: 25일 지급, 27일 도달 → 그 달 급여 압류 X).
- 노동법 적용원칙(특별법 우선, 1차 §5):

| 대상 | 압류 |
|---|---|
| 퇴직연금 가입자(DB·DC) | **전액 불가** → 퇴직금 100% IRP 입금 |
| 퇴직연금 미가입자(퇴직금제도) | 민사집행법 **1/2** |
| 임원 | 민사집행법 **1/2** |

## 5. 사내적립 vs 사외적립 · 수급권 · IRP 이전 프로세스

📘 교재 p.221

| | **사내적립** | **사외적립** |
|---|---|---|
| 제도 | 퇴직금제도(미가입자) | 퇴직연금(DB/DC) |
| 적립 위치 | 회사 내부 | 연금사업자 |
| 지급 주체 | 회사 직접 | 연금사업자 |
| 위험 | 회사 도산 시 퇴직금도 위험 | **근로자 수급권 보호**(부담금은 회사로 회수 불가, 퇴직금 재원으로만) |

- 국가가 퇴직연금 권장(임금채권보장 부담↓). 퇴직 시 연금사업자에 **퇴직급여 지급신청서**(=**퇴직통보**) 제출.

> 🛠️ **시스템 개발 포인트 — IRP 이전 처리 프로세스(공통)**
> 1. 퇴직 전 직원에게 **IRP 계좌개설 요청** → 사본 수령
> 2. **(DB)** 퇴직금 계산(30일분 평균임금×근속연수) / **(DC)** 퇴직시점까지 **미납 부담금 납입**
> 3. 연금사업자에 **퇴직급여 지급신청서(퇴직통보)** 제출 → 연금사업자가 IRP로 지급
> 4. **국세청 세금신고**(원천징수)

**DB vs DC 회계 (★)**

| | DB | DC |
|---|---|---|
| 부담금·운용수익 귀속 | **회사** | **직원** |
| 퇴직 시 회사 산정 | 필요(평균임금 계산) | 불필요(부담금만 납입) |
| 회계 | 퇴직급여충당부채 설정 + 퇴직연금자산, 운용수익만큼 부담금 납입 대체 | **충당 불요·회계처리 없음** |

- 357 법칙(연금사업자 농담): IRP 입금 후 예금 3일/펀드 5일/해외펀드 7일이면 해지 가능 → 직원이 해지해 일시금 수령 가능하므로 IRP 강제가 실질적으론 느슨한 면.

## 6. 퇴직금제도 상세 (IRP 의무화·중간정산)

📘 교재 p.222~228, 252, 257

### 6-1. IRP 이전 의무화 (2022.4.14)
- **2022.4.14부터** 퇴직금제도(미가입자) 퇴직금도 **전액 IRP 입금 의무**. 단 **중간정산금은 IRP 이전 요청 안 함**.
- **IRP 이전 예외**(급여계좌 지급 가능): ① 55세 이후 퇴직 ② 퇴직급여 **300만원 이하** ③ 사망 등.

### 6-2. 대출 미상환 퇴직자 처리 (2022.4.14 이후 전액 IRP라 퇴직금 직접 공제 불가)
| 방법 | 내용 | 비고 |
|---|---|---|
| ① 입금동의서 | IRP 입금과 동시에 해지해 회사에 상환 동의 | 근퇴법 위반(벌칙 없음). 공공기관은 감사 문제 |
| ② 신용보증기금 구상권 | 보증기관에 청구 | 정석 |
| ③ 급여계좌 지급(편법) | 그냥 급여계좌로 | 근퇴법 위반(벌칙 없음). **직원 과세이연 박탈** → 지양 |

> ⚠️/🛠️ **핵심** — 현행법상 회사 벌칙은 **"퇴직금 미지급"** 에만 있고 **"IRP 미입금"엔 벌칙 없음**(노동부 시정조치는 가능). 부득이할 때만 ③ 사용, 무분별 금지. 시스템은 정상 경로(전액 IRP) 기본, 예외는 사유코드로 관리.

### 6-3. 중간정산
- **사유 충족 시에만 가능**(교재 p.252 사유 요약). 증명서류 받아 **퇴직 후 5년 보관**(교재 p.257).
- **사유 미충족 지급 시 무효** → 직원 요구하면 **전체 근속기간 퇴직금 재산정** 지급. 기지급 중간정산금은 **부당이득반환청구**로 회수(교재 p.227).
- **평균임금 기준시점 = 신청일**(중간정산 대상기간 마지막날 아님). 정산 단위기간 제한 없음(원하는 기간만 선택 가능).
- 회사 내부 처리지침은 보통 **"신청 시점까지 일괄 정산"** 으로 통일.
- 중간정산 후 1년 미만 근무 후 퇴직: 전체 근속 1년 이상이면 **잔여 1년 미만분도 퇴직금 지급**(개월수/12 비례).

> 🛠️ **시스템 개발 포인트** — 중간정산은 ①사유코드+증빙 검증 ②평균임금=신청일 기준 ③정산 후 근속 재기산 ④잔여기간(1년 미만이라도) 비례 지급. **중간정산금은 IRP 의무이전 제외**.

> 💡 중간정산을 많이 받으면 총퇴직금이 **줄 수 있음** — 임금상승 누적효과 상실(중간정산자 총액 < 미정산자). 관계사 전출 시 직접 지급 대신 **승계**시키는 이유도 동일(중간정산 효과 회피).

## 7. 확정급여형(DB) 상세

📘 교재 p.229~235, 237

- **DB = 퇴직급여(퇴직금) 확정**: 직원은 30일분 평균임금×근속연수만 받음. 회사가 부담금을 적게/많이 납입해도 직원 수령액 불변.
- 회사 부담금·운용수익 = **회사 것** → 운용수익만큼 차기 부담금 납입 대체(변동). 회계: 퇴직급여충당부채 설정, 퇴직 시 퇴직연금자산과 상계.

### 7-1. 최소적립금 (교재 p.230)
- **최소적립금 = 기준책임준비금(=퇴직금추계액) × 의무적립비율**. **2021.1.1부터 100%**.
- 퇴직금추계액 = **보험수리기준**(근속·퇴직 예측) vs **일시퇴직기준**(기준일 전원 퇴직 가정) 중 **큰 금액**.

### 7-2. 재정검증·부족 해소·운용위원회
- **재정검증 통보**(p.230): 연금사업자가 매 사업연도 종료 **6개월 내** 적립금의 최소적립금 충족 여부 평가·통보.
- **부족 해소**(p.231): **95% 미달** 시 부족분 **1/3 이상**을 1년 내 납입. 미납 시 과태료(실무상 시정조치).
- **적립금운용위원회**(p.232~233): **상시근로자 300인 이상 + DB 운영** 회사는 **연 1회 이상** 개최(상시근로자 기준이지 DB 가입자 300인 아님). 위원장 포함 5~7인. **최소적립금 미달 사업장은 노동조합(대표) + 외부전문가 각 1명 이상 의무 포함**. 적립금운용계획서(목표수익률·자산배분) 심의 — 연금사업자(주관사) 지원.

### 7-3. 급여 지급 (교재 p.234)
- 적립금 범위 내 지급. **100% 적립** 시 연금사업자가 전액 지급(회사는 지급신청서에 금액 기재).
- 적립비율 미달(예 90%)이면 연금사업자가 **90%만**, **나머지 10%는 회사가 추가 지급**(통상 퇴직 시점에 추가 납입).

### 7-4. 세제혜택 (교재 p.237) — 일반기업 DB 도입의 실제 이유
- 회계상 퇴직급여충당부채는 **세법상 손금 전액 부인**.
- 퇴직연금에 **납입한 부담금**만 손금 인정(**퇴직연금조정명세서**).
- 예: 추계액 100억 중 20억을 부담금 납입 → 20억 손금 인정 → 과세표준 80억. = **기한이익**(절감보다 이연 성격).

> 🛠️ **시스템 개발 포인트** — DB는 충당부채/퇴직연금자산/운용수익 회계 + 최소적립금·재정검증 산식이 핵심. 추계액 = max(보험수리, 일시퇴직). 적립비율 < 100% 시 회사 추가지급분 산정 로직 필요.

## 8. 확정기여형(DC) 부담금 산정 (★ 시스템 핵심)

📘 교재 p.238~242

- **DC = 부담금 확정**: 연간 임금총액 × **1/12** 이상.
- **연차수당**: DB 평균임금엔 직전분만, **DC 임금총액엔 전부 포함**(퇴직으로 발생한 연차수당도 포함).
- **보상휴가 미사용수당**: **당해 연장근로분만** 평균임금 산입(전년도 연장근로분 제외). DC는 임금이므로 포함.

> 🛠️ **시스템 개발 포인트 — DC 부담금 만능 공식**
> ```
> 연간 DC 부담금 = 해당 사업연도 임금총액 × 1/12
>
> 분해(강사 니모닉):
>  · 매월 지급 임금(기본급·직무수당 등):
>      - 1년 정상근무  → 1개월분 (= 연간 매월임금합 ÷ 12)
>      - 휴직 등으로 일부만 임금 → (정상근무 임금합 ÷ 정상근무 개월수) = 1개월분
>        (휴직기간도 근속 포함이므로 1년치 납입, 임금은 정상분으로 환산)
>      - 연중 입·퇴사로 재직 N개월만 → (1개월분) × (N/12)
>  · 매월 미지급 임금(연차수당·상여 등): 무조건 × 1/12 (전액)
> ```
> ⚠️ 강사는 위 1/12을 "10분의 1"로 표현 — STT/구어 오인식, 실제 **1/12**. 통합 단계 확정.

**케이스별 (강사 예시)**

| 케이스 | 매월임금 부분 | 연차/상여 |
|---|---|---|
| 1년 정상근무 | 1개월분 (연간÷12) | ×1/12 |
| **연중 전체 휴직** | **전년도 부담금 수준** 납입 | — |
| **일부 휴직**(예 7~12월 휴직, 월200만) | (1~6월합 1200만 ÷ 6) = 200만 | + 연차 ×1/12 → ≈210만 |
| **연중 4개월 재직 후 퇴직**(월240만) | 240만 × 4/12 = 80만 | + 연차 ×1/12 |

- **무단결근**: 부담금 산정기간에 **포함**(유·무급 불문) → 부담금 낮아짐. **징계 정직**도 포함.
- **평균임금 최저보장(통상임금) 비교는 DC에 적용 안 함** → DC는 무조건 ×1/12.

### 8-1. 공제·감액 불가
- 회사채무(대출금·주식 매입대금·국민연금전환금 등)를 DC 부담금에서 **공제 불가**. 법정부담금(연간임금 1/12)은 **법정퇴직금과 동일하게 감액 불가**(비위행위자도 불가).
- (참고) **변형급여**(2004~5년 초기 퇴직연금): DC가 DB보다 적으면 회사가 차액 보전 — **현재 폐지**, 초기 도입사에만 잔존.
