## 1. 중간정산 시 근속기간 표기 — 세법 vs 노동법

📘 교재 p.99, 108

| 기준 | 근속기간 |
|---|---|
| **세법** | 중간정산 **지급한 날**까지 (지급일 = 퇴직소득 수입시기) |
| **노동법** | 중간정산 **대상기간**까지 |

- 두 인식 차이로 생긴 기간은 퇴직소득 원천징수영수증의 **제외월수**에 기재해 노동법 근속과 일치시킴.
- **근속연수 기재**: 입사일 / 기산일 / 퇴사일. 중간정산 받은 적 있으면 **기산일 = 중간정산 다음 날**. 없으면 입사일 = 기산일.

> 🛠️ **시스템 개발 포인트** — 퇴직소득 원천징수영수증 근속연수란 = 입사일·기산일·퇴사일 + 제외월수. 중간정산 이력 시 기산일 보정.

## 2. 퇴직소득세 계산 구조 (★ 시스템)

📘 교재 p.99~106, 139

> 🛠️ **계산 체인**
> ```
> ① 퇴직급여 (= 세법상 퇴직소득)
> ② − 근속연수공제
> ③ 환산급여 = (퇴직급여 − 근속연수공제) ÷ 근속연수 × 12
> ④ − 환산급여공제
> ⑤ = 과세표준
> ⑥ × 종합소득세율(간편법: ×세율 − 누진공제) = 환산산출세액
> ⑦ ÷ 12 × 근속연수 = 퇴직소득 산출세액
> ⑧ − 세액공제(외국납부) − 기납부세액(중간지급분) = 신고대상세액
> ```

- **퇴직급여란**: 중간지급(=종전소득, 과거 받은 퇴직금) / 최종(현재 지급 퇴직금) 구분. 정산 시 합계.
- **근속연수공제**(교재 p.103~104) ⚠️ 금액 확인필요:

| 근속연수 | 공제액 |
|---|---|
| 5년 이하 | 100만 × 근속 |
| 5~10년 | 500만 + 200만 × (근속−5) |
| 10~20년 | 1,500만 + 250만 × (근속−10) |
| 20년 초과 | 4,000만 + 300만 × (근속−20) |

  - 예: 근속 10년 → **1,500만**.
- **환산급여 = (퇴직급여 − 근속연수공제) ÷ 근속연수 × 12**.
- **환산급여공제**(교재 p.104) ⚠️: 환산급여 구간별 공제(전액/60%/55%/45%/35% 등).
- **과세표준** = 환산급여 − 환산급여공제.
- **환산산출세액** = 과세표준 × 종합소득세율(간편법). **퇴직소득 산출세액** = 환산산출세액 ÷ 12 × 근속연수.

### 2-1. "12배"와 연분연승법의 의미 (개념)
- 퇴직소득이 근로소득보다 세부담이 낮은 이유 = **연분연승법**: 과세표준을 **근속연수로 나눠** 세율 적용 → 낮은 세율 → 다시 근속연수 곱. (예: 1,500만을 근속 3년으로 나눈 500만에 6% 적용)
- **12배**는 임의 숫자가 아님: 1년치 임금 환산(예 월 500만 × 12 = 6,000만 = 연봉)으로 맞추는 장치 → "환산급여" 표현. 퇴직금도 연봉처럼 환산해 과세.

### 2-2. 세액공제·기납부 (교재 p.139 ㉞~㉟)
- **㉞ 세액공제 = 외국납부세액**(해외파견 국외근로 퇴직금에 외국 퇴직세 납부 시 공제). 99% 해당 없음.
- **㉟ 기납부 / 기과세이연세액** = 중간지급분에 대한 퇴직소득세. (중간지급 없으면 0)

## 3. 이연퇴직소득세 (★)

📘 교재 p.139, 149~151

- **가세이연 = 면제 아님**, 원천징수·납부 시기를 **연금수령 시까지 이연**. (IRP 입금 강제의 대가로 도입)

> 🛠️ **계산식**
> ```
> 이연퇴직소득세 = 신고대상세액 × (IRP 입금액 ÷ 퇴직급여)
> 차감원천징수세액 = 신고대상세액 − 이연퇴직소득세
>   → 원천징수이행상황신고서 소득세등란(교재 p.172)에 기재
> ```
- IRP **미입금분**은 그만큼 **원천징수**(이연 안 됨). 향후 IRP 해지·연금수령 시 **연금사업자가 이연분 징수**.
- **이연퇴직소득세 계산란 작성 시점** = 퇴직금이 **IRP에 입금됐을 때**(입금액 0이면 미작성).
- 연금계좌 입금명세: **IRP 계좌(연금사업자·계좌번호·입금일)** 기재. 입금일 = IRP 실제 입금일(연금사업자에 확인, 통상 퇴직+3~5일).

### 3-1. 55세·연금계좌
- **연금계좌 = 연금저축계좌 + 퇴직연금계좌(IRP)**. 둘 다 입금 시 가세이연 가능.
- **55세 이전 퇴직**: IRP 이전의무 강제 → **연금저축 입금 불가**, IRP만.
- **55세 이후 퇴직**: IRP 이전의무 적용 X → IRP **또는 연금저축** 입금해도 가세이연 가능(직원 자유).

## 4. 60일 내 사후 IRP 입금 → 환급

📘 교재 p.160~167, 173

- 퇴직금을 **급여계좌로 받아 원천징수**했더라도, **60일 내 IRP(또는 연금저축) 입금**하면 가세이연 → 이미 징수한 세금 **환급**.
- **환급 절차**:
  1. 직원이 **가세이연계좌신고서**(교재 p.167) 제출(IRP 입금 사실 통보).
  2. 회사가 **당초 원천징수이행상황신고 수정신고**.
  3. 환급세액을 **환급한 달 정기분 원천징수이행상황신고서**(수정신고분 칸 A9)에 기재해 조정 → 차감 후 직원 IRP에 입금.

> 🛠️ **시스템 개발 포인트** — 가세이연계좌신고서 수신 → 원천징수 수정신고 → 정기분 신고서 조정 → 환급액 IRP 입금. 입금일 추적(연금사업자 조회).

## 5. 2026.7.1 퇴직소득 세액정산 개정 (★★ 핵심)

📘 교재 p.117~119, 127, 141~144

- **새 서식**(교재 p.141, 개정 2026.5.20): **가산세 위연(⑱)**, **부표(기납부 또는 비과세이연세액 명세서)** 추가.
- **적용 분기**: **6.30 이전 퇴직자 = 구 서식(교재 p.139)** / **7.1 이후 퇴직자 = 신 서식(교재 p.141)**.

### 5-1. 개정 경과 (3단계로 단순화됨)
1. 당초 개정안: 환급 여부 무관 퇴직소득 전부 재계산 (복잡)
2. 2차안: 환급 시 이연세를 퇴직소득에 비례 재계산 (번거로움)
3. **최종(2026.7.1)**: 환급 발생 시 **[신고대상세액 절대값]과 [기납부 원천세] 중 작은 금액**만 환급.

### 5-2. 핵심 변화
- **6.30 이전**: 세액정산 환급세액을 **그대로 환급**.
- **7.1 이후**: 환급세액은 **국세청에 실제 납부된 세금 범위 내에서만** 환급. (과거 중간지급분이 IRP에 입금돼 **미납**이면, 그만큼은 환급 불가)

> 🛠️ **시스템 개발 포인트 — 세액정산 결과 분기 로직**
> ```
> 세액정산 결과:
>  ├ 납부세액 발생         → 그대로 신고 (변화 없음)
>  └ 환급세액 발생
>      ├ 중간지급분이 개인계좌(실제 원천징수·납부됨)  → 종전대로 전액 환급
>      └ 중간지급분이 IRP 입금(가세이연 = 미납)
>            → 환급 = min(|신고대상세액|, 기납부 원천세)
>            → 부표(기납부·비과세이연세액 명세서) 작성 활성화
> ```
> **부표 활성화 트리거** = 중간지급분 가세이연(IRP) 체크 + 세액정산 환급 발생.

### 5-3. 부표 작성 (교재 p.119, 127, 143~144)
1. 퇴직자에게 **연금계좌 현황자료**(교재 p.144 "연금계좌 이연퇴직소득 수령현황명세서") 요구 → 직원이 금융기관에서 발급.
2. **기납부 또는 기과세이연세액 명세서**(교재 p.127, 143):
   - ① **이미 지급된 퇴직소득 명세** = 회사 자료(중간지급 당시 금액·차감세·가세이연 여부).
   - ② **이미 지급된 퇴직소득 중 이연퇴직소득 명세** = 연금사업자 자료(IRP **입금금액·인출금액·이연퇴직소득 잔액·원천징수세액**). → IRP 유지 중이면 인출 0·잔액 그대로, 해지했으면 인출·세금 기재.
3. **정산분 이연퇴직소득 차감액**:

> 🛠️ ```
> 정산분 이연퇴직소득 차감액 = max( A − B , 0 )
>   A = (영수증 ㊲ 기납부세액 − ㉞ 산출세액)
>   B = (기납부명세서 ⑥ 차감세 + ⑮ 원천세)
> 차감원천징수세액 = − min(|신고대상세액|, 기납부 원천세)  (환급 = 음수)
> ```
> → 이 차감액을 **연금사업자에 통보** → 연금사업자가 당초 이연세(예 572만)를 정산 후 금액(예 550만)으로 변경.

**예시**: 현재 퇴직금 600만 + 과거 중간정산 1.2억(IRP 입금, 이연세 572만). 세액정산 합산세액 550만 → 신고대상세액 550 − 기납부 572 = △22만(환급). 그러나 572만은 국세청 미납(이연) → 환급 불가. **차감원천징수세액에 0/△22 처리, 이연세 572 → 550으로 조정**해 연금사업자에 통보.

### 5-4. DC 세액정산
- DC + 회사 명예퇴직금처럼 합산정산 필요 시, **DC 연금사업자가 세액정산** 의무자. 회사는 퇴직통보 시 중간정산분 원천징수영수증을 함께 전달.

## 6. 세액정산 — 절세 효과·대상

📘 교재 p.112~116

- **효과**: 중간정산분 근속연수를 합산 → 환산급여↓ → 세율↓ → 환급. (퇴직소득세 ↓)
- **선택사항**(회사 의무 아님): 직원이 **중간정산분 퇴직소득 원천징수영수증을 회사에 제출**해야 정산. 회사 전산에 과거자료 없으면 직원이 세무서 발급(2002년 이전은 자료 없을 확률↑).
- **세액정산 대상 = 하나의 계약**(소득세법 시행령 §43 각호): 종업원→임원 승진, 합병·분할·전출 포함. **퇴직 후 재입사 = 별개 계약 → 정산 불가**.
- 🛠️ **임원 케이스 중요**: 직원→임원 승진 시 **직원기간 퇴직금 + 임원 퇴직금 합산 정산** 가능. 임원은 절감 단위가 큼(수천~수억). 여러 중간정산 시 1차 정산 입사일 ~ 마지막 정산 퇴사일로 합계 기재.

## 7. 연금수령 절세 (참고)

- IRP에서 **연금수령 한도 내** 인출 = 연금소득(분리과세) → **이연퇴직소득세의 70%만 과세**(=30% 절감).
- **연금수령 한도 = 연금계좌 평가액 ÷ (11 − 연금수령연차) × 120%**. 한도 내 인출이면 "연금수령"으로 간주(매달 안 받아도 됨).
- 2013.3.1 이전 가입자는 **6년차부터** 시작 → 정년(60세) 시 이미 다수 연차 → 일시금이어도 상당부분 연금수령 인정.

## 8. (Recap) 원천징수영수증 서식 — DC

- 퇴직금제도·DB = **퇴직소득 원천징수영수증**(회사). DC = **연금계좌 원천징수영수증**(교재 p.207, 연금사업자).
- (3차 §10 참조) 세금신고 = 원천징수이행상황신고 + 지급명세서. 지급명세서가 법적 신고서.

## 통합 단계(P2~P4)로 넘길 ⚠️ 검증 항목 (4차 추가분)
- 퇴직소득세 계산: 근속연수공제표·환산급여공제표 금액(구간별), 12배·연분연승법
- 이연퇴직소득세 = 신고대상세액 × (IRP입금액/퇴직급여), 차감원천징수
