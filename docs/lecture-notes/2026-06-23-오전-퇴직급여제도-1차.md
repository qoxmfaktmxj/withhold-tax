## 0. (예고) 2026.7.1 퇴직소득 세액정산 개정 — ⚠️ 별도·미완

> ⚠️ **1차출처 확인 필요 / 강의에서 예고만** — 강사가 "내일(2차/오후 회차) 1시간 정도 다룬다"며 개요만 언급. 전사문이 매우 불완전하여 아래는 **잠정 요지**. 정확한 시행일·서식·계산식은 후속 강의 + 1차출처로 확정 예정.

- **개정 경위**: 당초 개정안(복잡한 계산방식)이 "너무 복잡하다"는 의견으로 2026년 5월 **단순화** 재개정 → **7월 1일 적용**(시행일 ⚠️ 확인필요).
- **핵심 취지**: 퇴직소득 세액정산에서 **환급세액은 국세청에 실제 납부된 세금 범위 내에서만 환급**. 납부되지 않았다면 환급 발생분만큼 **이연퇴직소득세를 조정**.
- **환급은 드문 케이스**: 일반적으로 퇴직소득 세액정산 시 환급은 잘 발생하지 않음. 발생 예시:
  - 정년퇴직 정산 후 **계약직 재고용** → 계약 종료 시 중간지급분이 커져 합산 정산 시 환급 가능
  - **임금피크제**로 피크 시점에 중간정산한 경우
- **부표 작성**: 환급 발생 + 과거 중간지급분이 IRP 등에 입금되어 합산 세액정산에 포함된 경우에 작성. (환급 미발생/단순 케이스는 부표 미작성)
- **연금계좌 현황자료 요구**: 환급 발생 시 직원에게 **연금계좌 현황자료**를 요구 → 중간정산 퇴직금이 IRP에 유지 중인지/해지됐는지 확인.
  - 해지된 경우: 이미 금융기관 단계에서 세금이 납부되어 있음 → 조정할 것이 없음.
- 🛠️ **시스템 개발 포인트** — 일반 담당자는 "환급=무조건 정산"이 아니라 ①중간지급분 IRP 입금 + ②합산 세액정산 시 환급 발생 시에만 정산, ③연금계좌 현황자료 요구 정도만 알면 됨. **시스템은 위 환급/조정/부표 로직을 설계해야 함** → 후속 강의에서 계산식 확정 후 구현.

## 1. 퇴직급여제도 개관

📘 교재 p.43, 52~54

**퇴직급여제도** = 직원이 퇴직할 때 퇴직금을 얼마 지급할지 규율하는 제도. 종류는 다음과 같다.

| 제도 | 다른 표현 | 퇴직금 산정 | 지급 주체 |
|---|---|---|---|
| **퇴직금제도** | 퇴직연금 **미가입자** | 30일분 평균임금 × 근속연수 | 회사 직접 |
| **DB**(확정급여형) | 퇴직연금 가입 | 30일분 평균임금 × 근속연수 (퇴직시점 평균임금) | 연금사업자 |
| **DC**(확정기여형) | 퇴직연금 가입 | **회사 납입 부담금 누계 + 운용수익** | 연금사업자 |
| **혼합형** | DB+DC 결합 | DB·DC 비율로 각각 산정 (예: DB 99 : DC 1) | 연금사업자 |

- **퇴직금제도(미가입자)와 DB는 퇴직금 산정식이 동일**(30일분 평균임금×근속연수). 차이는 지급 주체(회사 vs 연금사업자).
- **DC는 다르다**: 회사가 매년 납입한 부담금(연간 임금총액의 1/12)에 **운용수익**을 더한 금액이 퇴직금 → 회사는 퇴직 시점에 퇴직금을 "산정"하지 않고, **부담금만 납입**.

> 🛠️ **시스템 개발 포인트**
> - 직원의 제도 구분(미가입/DB/DC/혼합형)에 따라 퇴직금 산정 분기가 완전히 달라짐 → 직원 마스터에 제도 구분 필수.
> - DB/미가입자: 퇴직 시 **평균임금 계산 엔진** 호출. DC: 퇴직 시 회사 산정 없음(부담금 납입 이력 + 연금사업자 운용수익).
> - 혼합형: DB·DC 비율 파라미터로 두 산정을 합산.

**DC vs DB 선택 시 고려(직원 관점)**
- DB는 **퇴직시점 평균임금** 기준 → 호봉/임금인상이 복리처럼 누적 반영(입사부터 마지막 평균임금으로 전 기간 재산정 효과).
- DC는 매년 부담금을 납입 → 임금인상은 단순율로만 반영(복리 효과 없음). 대신 **운용수익**으로 DB를 초과할 수 있음(운용 잘하면 유리, 못하면 불리).
- → 운용 자신 없으면 DB 선호. 그래서 기금형(전문 매니저 운용)으로 수익률을 높이려는 흐름도 있음.

## 2. 퇴직금의 개념과 청구권

📘 교재 p.43~44, 46

- **퇴직급여** = 종업원이 **퇴직(간주퇴직 포함)** 할 때 퇴직급여제도에서 지급하는 금액.
- **근로소득 vs 퇴직소득**: 둘 다 고용관계에서 받는 소득. 근로소득 = 근로제공 기간에 실현된 소득, 퇴직소득 = **퇴직함으로써** 실현된 소득.
- **청구권 발생시점 = 퇴직 시**. 퇴직 전에는 퇴직금 청구 불가 → 퇴직 전에 지급하면 퇴직금으로 인정 못 받고 **회사가 빌려준 돈(대여금)** 으로 본다.
- **실무 귀결**: 직원이 퇴직하면 퇴직금 지급 + 세금 신고. **세금 신고 시점은 "퇴직했을 때"**(실제 퇴직 + 간주퇴직).

### 2-1. 지급의 강제성

📘 교재 p.43

- 퇴직금은 **지급 약정이 없어도 반드시 지급**. 받지 않겠다는 노사 약정도 **무효**.
- ⚠️ 근퇴법 **§44 벌칙**: 14일 내 퇴직금 미지급 시 **3년 이하 징역 또는 3천만원 이하 벌금**(수치 확인필요).
- **반의사불벌**: 피해자(직원)의 명시적 의사에 반하여 공소 제기 불가 → 직원이 문제를 제기해야 불거짐(통상임금 소송처럼). 잘못 계산해도 직원이 모르면 자동으로 문제되진 않음.

### 2-2. 지급시기의 강제성

📘 교재 p.78

- **퇴직일로부터 14일 이내 지급**.
- ⚠️ 미지급 시 **지연이자 연 20%**(미지급 퇴직급여 지연이자, 확인필요).
- **노동법 14일에는 세법의 "기한 특례"가 적용되지 않음**:

| | 세법(원천세 등) | 노동법(퇴직금 14일) |
|---|---|---|
| 마감일이 토·일·공휴일이면 | 다음 영업일로 연장(기한특례) | **연장 없음** — 주말·공휴일 포함해 14일 |
| 실무 처리 | 다음 영업일까지 납부 | 그 **전날까지** 지급 |

> 🛠️ **시스템 개발 포인트** — 퇴직금 지급기한(14일)은 **달력일 기준**(주말·공휴일 미차감). 세금 납부기한 로직(기한특례)과 **분리**해서 계산해야 함.

## 3. 현실적 퇴직 vs 간주퇴직

📘 교재 p.32~33

| 구분 | 내용 | 지급 의무 |
|---|---|---|
| **현실적 퇴직** | ① 종업원 퇴직(사망 포함) ② 법인 합병·조직변경·사업연도 종료 ③ 출자관계 법인 전출(관계사 전출) ④ 상근→비상근 ⑤ 비정규직→정규직 전환 | **반드시 지급** |
| **간주퇴직** | 계속 근무 중이나 세법이 퇴직으로 인정 → **중간정산 / 중도인출** | **임의**(줘도 되고 안 줘도 됨) |

### 3-1. 노동법 vs 세법 — 같은 사건, 다른 취급

- **비정규직 → 정규직 전환**
  - 세법: 퇴직금 지급하면 퇴직으로 인정.
  - 노동법: 계속 근무 → 퇴직 아님. 퇴직금 미지급 시 근속은 **최초 입사부터** 기산.
- **직원 → 임원 승진**
  - 세법: 퇴직금 지급하면 퇴직으로 인정.
  - 노동법: 고용관계 종료 = **당연퇴직**(중간정산 개념 아님). 미지급 시 근속 최초 입사부터.
  - 임원 미지급은 **임금체불이 아니라 계약위반** → 법원 소송(노동부 진정 아님).
- **관계사 전출**: 퇴직금을 **승계**시킬 수 있음(반드시 지급할 필요 없음) → 전입 법인이 근속 승계.

### 3-2. 중간정산·중도인출과 제도변경

- **중간정산** 신청 가능자 = **퇴직금제도(퇴직연금 미가입자)**. 회사는 거부 가능. 승인해 정산하면 근속기간 **새로 기산**.
- **중도인출** 신청 가능자 = **DC 가입자**.
- **DC 부담금 납입의 세무**: DC 부담금 납입은 퇴직급여 비용처리지만, **세금신고(원천징수) 대상 아님**(퇴직이 아니므로).
- **제도변경(DB→DC 전환)**: 과거 DB 가입기간을 소멸시키고 DC 부담금으로 **일시납** → 이는 **간주퇴직(중도퇴직)** → **세금신고 대상**.
  - 예: 10년 근속 DB → DC 전환 시 과거기간 부담금(예: 3,400만원)을 일시납 = 과거 근속 퇴직금 정산 = 신고 대상.

> 🛠️ **시스템 개발 포인트**
> - **간주퇴직 = 세금신고 트리거**. 중간정산↔퇴직금제도, 중도인출↔DC로 신청권 분기.
> - 단순 DC 부담금 정기납입: 신고 대상 아님. **DB→DC 전환 일시납: 신고 대상**(중도퇴직). 이 둘을 코드에서 구분.

## 4. 경영성과급 DC 추가납입

📘 교재 p.27

**왜 하나** — 경영성과급을 DC 부담금으로 적립해 **퇴직소득으로 인정**받으면 ① 세부담↓(분류과세·근속연수 효과) ② **4대보험 비부과**.

**핵심 요건 — 노동법상 "임금"이 아니어야** 추가납입 가능 (임금이면 불가; 임금을 법정부담금 대신 추가납입에 돌리면 회사만 이득):

| 성과급 종류 | 노동법상 성격 | DC 추가납입 |
|---|---|---|
| **경영평가성과급**(개인 등급 차등 지급) | **임금**(근로의 質·量 평가) | ❌ 불가 |
| 공공기관 경영평가성과급 | **임금** | ❌ 불가 |
| **PI/PS**(영업이익 기반 집단 성과급) | 원칙 **비임금**(이익 공유) | ✅ 가능 |
| └ 예외: 삼성전자류 | 취업규칙 명시 + 생산목표·불량 등 **통제지표** 평가 → **임금** | ❌ 불가 |

- **DB 부담금으로는 납입 불가** — DB 퇴직금에 영향이 없어 회사만 이득. **DC만 가능**. ⚠️(노동부 행정해석 2012~2013, 확인필요)
- **적립요건** ⚠️(근퇴법 시행령, **2015.2.3 이후** 적립분, 확인필요):
  1. 가입대상 근로자 **전원** 적립 — 단 **적립 미희망 직원은 향후 미적립 선택 가능**(강제 아님).
  2. 근로자가 적립금액을 **임의 변경할 수 없는 적립방식** 설정. 노사합의 비율(예: 20%)만큼 → **전액 100% 아니어도 됨**.
- **부담금 구분**: 법정부담금(연간 임금총액 1/12) + **추가부담금**(경영성과급).
- **혼합형 운영 동기**: DB 선호 직원이 경영성과급을 적립하려면 DC 경로가 필요 → DB 99 : DC 1 식 혼합형으로 DC 통로 확보.

> 🛠️ **시스템 개발 포인트** — 추가부담금(경영성과급)은 법정부담금과 별도 항목. 성과급 종류별 임금성 플래그 + 적립요건(전원/미희망 제외/임의변경 불가 비율) 검증 로직 필요.

## 5. 노동법 적용원칙

📘 교재 p.47, 56

두 원칙을 적어둘 것:
1. **특별법 우선 원칙** — 근퇴법(특별법)이 회사규정·민사집행법보다 우선.
2. **유리조건 우선 원칙** — 회사규정이 근퇴법보다 근로자에게 유리하면 회사규정 적용.

### 사례 ① 퇴직금액 (특별법 vs 유리조건)

| 회사규정 | 근퇴법(30일분×근속) | 적용 | 근거 |
|---|---|---|---|
| 3천만원 | 4천만원 | **4천만원** | 회사규정이 미달 → 특별법 우선(미달분은 임금체불) |
| 4천만원 | 3천만원 | **4천만원** | 회사규정이 유리 → 유리조건 우선 |

→ 근퇴법의 30일분 평균임금×근속연수 = **법정 최저한**. (교재 p.56 "법정 최저한")

### 사례 ② 압류 (특별법 우선)

- 근퇴법: 퇴직연금 **전액 압류 불가**. ↔ 민사집행법: 퇴직금 등 **1/2까지 압류 가능**.
- 두 법이 충돌 → **특별법(근퇴법) 우선**:

| 대상 | 적용 법 | 압류 |
|---|---|---|
| 퇴직연금 **가입자** | 근퇴법(특별법) | **전액 불가** |
| 퇴직연금 **미가입자**(퇴직금제도) | 근퇴법 압류규정 적용 안 됨 → 민사집행법 | **1/2 가능** |
| **임원** | 근로자 아님 → 근퇴법 미적용 → 민사집행법 | **1/2 가능** |

## 6. 설정 제외대상 · 임원 · 차등금지

📘 교재 p.49

### 설정 제외대상 (퇴직금 지급의무 없음)
- **계속근로 1년 미만** / **주 소정근로시간 15시간 미만**.
- 일용직도 **1년 이상** 고용하면 퇴직금 지급.
- **사업소득 원천징수자**라도 회사의 **지휘·감독**을 받으면 실질은 근로자 → 퇴직금 지급. (세법 ≠ 노동법, 실질 판단)

### 임원
- 임원은 근로자 아님 → 근퇴법상 퇴직금 의무 없음.
- 회사 **퇴직급여 규정**이 있으면 **계약관계**로 지급. 규정 없으면 의무 없음.
- 미지급 시 **임금체불 아닌 계약위반** → 법원 소송(노동부 진정 불가).
- 단, 회사에 퇴직금 규정이 **전혀 없어도** 직원(근로자)에게는 근퇴법에 따라 반드시 지급.

### 차등금지 (실무 2대 포인트)
1. 정규직은 DB/DC 선택권, **비정규직은 DC만 강제** → 차등금지 **위반 소지**.
2. **명예퇴직금은 IRP 의무이전 대상 아님** → 직원 간 퇴직금 차등 노출 방지(§10 참조).

## 7. 퇴직소득의 조세 가세체계 — 근로소득보다 유리한 이유

📘 교재 p.47~48

1. **분류과세**: 다른 소득과 **합산하지 않음** → 세율↓.
   - (대조: 이직 시 전직장 근로소득과 합산되면 과표↑·세율↑ → 연말정산 추가납부 발생)
2. **근속연수가 길수록 세금↓**: 세액정산(과거 중간정산분 합산)으로 **근속연수를 끌어와** 세금이 줄고 환급이 발생할 수 있음.
3. **4대보험 비부과**. → 경영성과급을 DC로 적립하려는 동기(§4).

**절세 방법**: ① 근속기간을 실제대로 가져가기 ② **세액정산 방식**으로 신고.

## 8. 평균임금 vs 임금총액

📘 교재 p.52, 56~57

### 8-1. 세법 총급여 ≠ 노동법 임금
- 세법 **총급여** = 급여 − 비과세소득. (과세 목적)
- 노동법 **임금** = 사용자가 **근로의 대가**로 지급한 것 전부. **비과세소득(예: 식대)도 노동법상 임금에 포함**.
- 노동법은 급여를 **임금 vs 금품**으로 구분. **금품**은 평균임금·통상임금에 미포함 → 퇴직금·연장수당 산정 제외. (직원은 임금이 유리, 회사는 금품이 유리 → 분쟁 소지)

### 8-2. 자가운전보조금 — 성격에 따라
- 시내출장 여비(실비) 성격 → **금품**(비임금). (출장 실적 입증 필요하나 소수 임직원 대상이면 국세청 관심↓)
- 출장 실적 없이 전원에게 정기 지급 → **수당 = 임금**.

### 8-3. 성과급 임금성 (대법원 판례)
- **경영평가성과급**(개인 차등) = **임금**.
- **PI/PS**(영업이익 기반 집단) = 원칙 **비임금**(이익 공유, 근로 대가성 약함).
  - 예외: **삼성전자 케이스** — 취업규칙 명시 + 생산목표·불량 등 개인 통제지표 평가 → **임금**.

### 8-4. 평균임금 ≠ 임금총액 (★ 핵심 구분)

| | **평균임금** | **임금총액** |
|---|---|---|
| 쓰임 | DB·퇴직금제도 **법정퇴직금** 산정 | **DC 부담금** 산정 |
| 연차수당 | **직전 수령분만** ×3/12 (통상의 생활자금) | 전부 포함 |
| 범위 | 직전 3개월 + 일부 안분 | 해당 기간 임금 전부 |

> 🛠️ **시스템 개발 포인트** — DB/미가입자 퇴직금은 **평균임금**, DC 부담금은 **임금총액** 기준. 두 산정 베이스를 혼동하면 안 됨(연차수당·상여 처리가 다름).

## 9. 1일 평균임금 → 법정퇴직금 계산

📘 교재 p.56~57, 59, 62~63, 70~71

### 9-1. 3개월 임금총액 구성

```
3개월 임금총액 = ① 매월 지급 임금(직전 3개월분)
              + ② 상여금   (직전 1년분 × 3/12)
              + ③ 연차수당 (직전 수령분 × 3/12)
```

> ⚠️ **1차출처 확인 필요** — 전사문상 상여·연차 배율이 "10분의 3"으로 들리나, 표준 산정은 **3/12(=직전 1년분을 3개월분으로 안분)**. 통합 단계에서 정확 배율 확정.

- **통상의 생활자금 원리 → 중복 배제**: 직전 1년 조회 시 명절상여 2회·연차수당 2회가 들어와도, 평균임금엔 **직전 1회분만** 반영(중복 배제). 이유: 평균임금은 "통상의 생활자금이 반영된" 개념.
- **연차수당**: **직전 수령분만**(퇴직 연도 1월에 부여된 연차 아님 → 그 직전에 받은 연차수당).
- **임금인상 소급분**: 해당 3개월 귀속분만 포함(그 외 월 귀속분 제외).
- **확정 시점**: 평균임금은 **퇴직시점에 지급되었거나 확정된 것만** 포함. 퇴직 후 확정된 성과급은 미포함(재계산 불요).

### 9-2. 1일 평균임금과 총일수

```
1일 평균임금 = 3개월 임금총액 ÷ 3개월 총일수
```
- **총일수 = 89~92일** 사이로 형성. 퇴직 시점에 따라 달라짐(정상 — 같은 급여라도 4/30 퇴직과 5/30 퇴직의 총일수가 다름).
- **달력상 역(曆)으로 소급**: 일수가 아니라 **달력 단위(한 달씩)**로 역산. 예: 9/15 퇴직 → 8/16, 7/16, 6/16 … 한 달씩 "통" 친다.
- **초일불산입**(민법): 마지막 근무일은 빼고 다음 날부터 기산.

### 9-3. 퇴직일 개념 (노동법/4대보험 ≠ 세법)

| 기준 | 퇴직일 | 예: 12/30 마지막 근무 |
|---|---|---|
| **노동법·4대보험** | 마지막 근무일의 **다음 날** | 1/1 |
| **세법** | 마지막 근무일 | 12/30 |

- 14일·3개월 기산도 **마지막 근무일(초일) 불산입**, 다음 날부터.

> 🛠️ **시스템 개발 포인트**
> - 퇴직일을 노동법/4대보험용(마지막근무+1)과 세법용(마지막근무일)으로 **이원 관리**.
> - **소수점 처리**: 1일 평균임금 소수점은 ⚠️ 유권해석상 **올림(절상)**, 일반 실무는 절사(라운다운)도 통용. 시스템은 **법 부합(올림)** 으로 설계 권장(직원 유리·분쟁 회피). 정확 자릿수는 확인필요.

### 9-4. 법정퇴직금

```
30일분 평균임금 = 1일 평균임금 × 30
법정퇴직금      = 30일분 평균임금 × 근속연수
```

- **근속연수**: 입사 ~ 퇴직(근로계약 체결~해지). **휴직기간 포함**.

> 🛠️ **시스템 개발 포인트** — 휴직기간도 근속에 포함 → **DC 가입자는 휴직기간에 대해서도 부담금 납입** 필요(근속에 들어가므로 퇴직금 대상).

## 10. IRP 이전 의무와 원천징수

- **근퇴법**: 퇴직 시 **법정퇴직금 전액 IRP 입금 의무**.
- **원천징수 연결**: IRP에 **입금되지 않은** 퇴직금은 **원천징수(세금 차감)**, IRP **입금분**은 **이연**(세금 미차감).
- **법정외퇴직금(명예퇴직금·공로금 등)**: IRP 이전 **의무 아님** → 직원이 **선택**(급여계좌 수령 가능). 이유: 차등금지(명퇴금까지 IRP 강제 시 직원 간 퇴직금 차등 노출).

**예시** — 퇴직금 8천만원 = 법정퇴직금 5천 + 명예퇴직금 3천, 명퇴금을 급여계좌로 수령:
- IRP 입금 = **5천만원** → 이연퇴직소득세는 **5천 기준**.
- 명퇴금 3천은 급여계좌 지급 → **원천징수**(세금 차감).

> 🛠️ **시스템 개발 포인트** — **이연퇴직소득세 = IRP에 입금된 퇴직금 기준**으로 산정. 법정퇴직금/법정외퇴직금 분리 + IRP 입금액 ↔ 급여계좌 지급액에 따라 이연/원천징수 분기. 이 때문에 퇴직소득 원천징수는 근퇴법(IRP 이전 의무)을 먼저 이해해야 함.

## 부록. 법정퇴직금 vs 법정외퇴직금

📘 교재 p.46

| | **법정퇴직금** | **법정외퇴직금** |
|---|---|---|
| 예 | 30일분 평균임금×근속연수 | 명예퇴직금, 공로금 |
| 성격 | **임금 후불**(근로의 대가) | 공로보상·위로금(근로 대가 아님) |
| 감액 | **불가** — 징계해고자도 법정 최저한 보장 | **가능**(비위행위자 감액 등) |
| IRP | 전액 이전 의무 | 이전 의무 없음(직원 선택) |

- 매년 **퇴직급여충당금** 설정 이유: 1년 근무마다 한 달분 퇴직금 **채무가 발생**, 지급만 미실현 → 임금 후불.
- **공공기관 감액규정**(공무원 규정 차용): 공무원과 신분이 달라 **유효성 의문**(대체로 무효로 보는 것이 타당).
