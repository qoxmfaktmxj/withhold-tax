## 🛠️ 시스템 개발 핵심 인덱스 (계산 로직이 있는 곳)
- **평균임금 vs 임금총액** (2차 §8) / **법정퇴직금 = max(평균임금, 통상임금)×30×근속** (2차 §3)
- **DC 부담금 만능 공식** (2차 §8, 3차 §1) — 매월임금 + 연차·상여 ×1/12, 휴직/연중 케이스
- **DC 미납 지연이자** 10%/20% (3차 §2)
- **제도 변경(DB→DC) 소급 부담금·간주퇴직 신고** (3차 §4)
- **임원 퇴직금 한도** = 2019이전×3배 + 2020이후×2배 (3차 §9)
- **원천징수 의무자** DB=회사 / DC=연금사업자, 합산신고 (3차 §10)
- **퇴직소득세 계산 체인**(근속연수공제→환산급여→산출세액) (4차 §2)
- **이연퇴직소득세** = 신고대상세액 ×(IRP입금액/퇴직급여) (4차 §3)
- **★2026.7.1 세액정산 환급 제한 + 부표 로직** (4차 §5) — 시스템 재설계 영향 최대

## ⚠️ 통합 단계 검증 항목 마스터 리스트 (1차출처 대조 필요)
**노동법(근퇴법)**
- 근퇴법 §44 벌칙(3년/3천만원), 미지급 지연이자 20%, 14일 기산(초일불산입)
- 평균임금 상여 ×3/12·연차 직전분 ×3/12 (녹취 "10분의3" = STT 의심), 통상의 생활자금·중복배제
- 평균임금 최저보장(통상임금 1일 환산 비교)·통상임금 산정시점(퇴직시점)
- 근속 제외 가능(병역·개인사정·약정육아휴직) vs 불가(징계정직·법정육아휴직)
- 최소적립금 100%(2021.1.1), 재정검증 6개월·부족분 1/3·95%, 적립금운용위(300인, 노조+외부전문가)
- 퇴직금제도 IRP 의무화 2022.4.14·예외(55세/300만/사망), 중간정산 사유·증빙 5년, 평균임금=신청일
- 제도 변경 수급권 방향(DB→DC 소급 가능/DC→DB 소급 불가), DB→DC 소급 부담금 = max(직전1년 임금총액×1/12, 평균임금 30일분)
- DC 부담금 부족분 소멸시효 10년(§20⑤) vs 임금 3년, 미납 지연이자 10%/20%

**세법(소득세법·법인세법)**
- 임원 퇴직급여 규정초과 = 근로소득(법인세법 시행령 §44④), 특별공로금 판단
- 임원 퇴직금 한도(2019이전 3배/2020이후 2배), 연평균 환산, 근로소득영수증 ⑮-3, 건보 제외
- 근속연수공제표·환산급여공제표 금액, 12배·연분연승법
- 이연퇴직소득세 산식, 55세 전후 IRP/연금저축, 연금수령 한도 ÷(11−연차)×120%·70% 과세
- 60일 사후입금 환급(가세이연계좌신고서)
- **★2026.7.1 세액정산 개정**: 신서식 ⑱·부표, 환급=min(|신고대상세액|, 기납부원천세), 부표 트리거, 정산분 이연퇴직소득 차감액=max(A−B,0), 연금계좌 현황자료(교재 p.144), 시행일
- 세액정산 대상 "하나의 계약"(소령 §43 각호), 국민연금 전환금 IRP 이전의무 제외·총액신고, 해고예고수당 퇴직소득
- 원천징수 의무자(DB 회사 / DC 연금사업자), 지급명세서=법적신고서, DC=연금계좌 원천징수영수증(교재 p.207)
